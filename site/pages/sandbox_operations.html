How-to guide

Operations and troubleshooting

{% include _docs_source.html %}

Update published packages

  1. Select a scoped release or advisory fix and review upstream release notes. Separate framework, SDK transitive, build-tool and OS changes.
  2. Keep package-versions.json, proxy npm manifests/locks, Python installation declarations/hash locks, and Java/Spring POM properties consistent.
  3. Rebuild and recreate affected services, then verify all fifteen installed releases with python examples/sandbox/run-published-packages.py --verify-only.
  4. Run targeted smoke/login checks and the full workflow for shared changes. Include version changes, relevant advisory, lockfile diff, tests and remaining findings in the PR.

registry-versions.py queries public registries and overwrites package-versions.json with their latest versions. It is not a read-only query or an automatic upgrade of every build declaration. Review its diff and reconcile all pins before committing. A local SDK checkout does not alter registry-installed containers.

Refresh dependencies deliberately

Use targeted npm updates in the affected proxy directory and review both manifest and lockfile. Avoid forced audit fixes and unrelated major upgrades. Serving images omit npm; audit the host lockfile or use the isolated tools image.

npm audit --prefix examples/sandbox/aiwaf-proxy --omit=dev --package-lock-only
docker compose --profile assessment-tools build aiwaf-audit-tools
python examples/sandbox/audit-published-proxies.py

The audit can remain nonzero after one fix because other advisories remain. A finding in an AIWAF transitive dependency may need an upstream package release; keep the sandbox issue scope explicit.

python examples/sandbox/lock-python-dependencies.py
python examples/sandbox/lock-python-dependencies.py --refresh-build-tools

The first command reads installed distributions from running Django/Flask/FastAPI containers and downloads their wheel versions to regenerate Linux x86_64 / CPython 3.11 hashes. It excludes the main AIWAF distribution and refreshes wheel/setuptools separately; preserve the AIWAF release pin/hash in each requirements.lock: the refresher excludes it and does not reinsert it. Use containers with the intended dependency set. The second command replaces only wheel/setuptools entries. Both require network access and modify lockfiles. Base-image digests and Java/Spring security overrides require explicit review too.

The TLS root/private CA material stays in assessment_tls_data. Export only the public root as described in TLS validation. After a large host clock jump, restart Caddy so it can renew its short-lived leaf certificates.

Preserve and inspect state

docker compose ps
docker compose logs --tail 100 aiwaf-django
docker compose exec redis redis-cli INFO keyspace
docker compose restart aiwaf-django

Normal restarts and docker compose down preserve named volumes. down -v deletes stored state and assessment CA data. Do not use it as a routine remedy for false positives. Global Redis flushing destroys other runtimes' evidence; use fresh synthetic clients and inspect service namespaces first. The isolated outage runner is preferable to stopping shared Redis during a test run.

Diagnose a failed check

SymptomCheck
Docker is unavailable or initializer image missingStart Docker Desktop with Linux containers; confirm docker version returns a server. Build aiwaf first so sandbox-aiwaf exists for the initializer. Its exit 0 is expected.
Installed-version assertion failsCompare the selected package inventory and build declarations with installed versions. Rebuild and recreate; restarting a container does not install a new image.
Registry install failsCheck Docker network/proxy access, selected package versions and wheel platform. Do not silently substitute a sibling checkout.
Django or burst requests time outFinish scans/builds, verify application/upstream health, and rerun the affected target alone. Record any timeout change; the matrix default is five seconds.
Normal requests are blocked after attacksInspect persistent reputation and actual forwarded client IPs. Verify namespaces and headers; avoid erasing state to hide false positives.
TLS verification failsUse localhost, the exported CA and both assessment profiles; inspect certificate time validity and Caddy logs. Keep certificate verification enabled.
Grype is slow on WindowsUse Docker's Linux engine and the dedicated database volume, not Windows bind-mounted SQLite storage. Inspect scanner errors; scan failure is not a clean result.
PHP blocks ordinary routesUse its separate Composer package and autoloader. Sandbox UUID-only path rules are disabled for Juice Shop. PHP remains outside the published-package scope.

Contributor tests and PR checklist

From the repository root, run the harness and dependency-free Redis helper tests:

python -m pip install requests
python -m unittest discover -s examples/sandbox -p 'test_*.py'
node --test examples/sandbox/common/redis-cache.test.js

The Python tests open local HTTP listeners. The proxy helper resolves httpxy from the current working directory, so install and run its test from the Express package directory using host Node.js 22/npm:

cd examples/sandbox/aiwaf-proxy
npm ci
node --test ../common/proxy.test.js
cd ../../..

For a proxy or dependency change, rebuild the affected service and run targeted smoke/login checks. Shared changes need the full published workflow. Record the commands and outcomes in the PR; keep generated reports, node_modules and secrets out of commits. Documentation-only changes should verify paths, options, service names and links against the repository.

The separate examples/sandbox/docker-compose.adapters.yml describes optional PHP Redis/MySQL adapter tests. It is not a root Compose override and requires its PHPUnit/vendor setup to be checked independently. The trainer/tests profiles likewise do not count as fifteen-runtime validation.

Generated files and cleanup

Keep source, Dockerfiles, committed locks, fixtures, tests and the latest evidence. Generated reports, bytecode, dependency directories, tool caches and exported TLS certificates are ignored and excluded from images. Delete only exact obsolete paths after confirming they belong to the sandbox; do not remove package manifests, lockfiles or every JSON file.

The stack contains a deliberately vulnerable application and synthetic forwarded-IP controls. Use an isolated evaluation environment. The fixture endpoints bind to loopback; normal proxy ports follow Compose bindings. Production network and trust policies need their own review.
