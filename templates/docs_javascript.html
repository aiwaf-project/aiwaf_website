AIWAF-JS Full Project Reference

Single exhaustive orientation document for engineers working in aiwaf-js.

Package
aiwaf-js
Version
0.1.0
Runtime
Node.js (LTS recommended)
CLI
aiwaf via bin/aiwaf.js

Purpose And Scope

  • System purpose and Node.js architecture.
  • Execution flows for Express + adapters (Fastify, Hapi, Koa, Nest, Next.js, Adonis, Sails alias).
  • Core modules and shared abstractions in lib/.
  • Storage, learning, and model lifecycle.
  • Security controls, exemptions, route-aware behavior, CLI, tests, and packaging internals.

Project Snapshot

  • Default entrypoint: index.js
  • CLI entrypoint: bin/aiwaf.js
  • Runtime integration model: middleware/plugin handlers for Node frameworks
  • Optional paths: maxmind GeoIP, redis client, aiwaf-wasm bridge

Top-Level Repository Structure

index.js

Exports framework integration surface.

lib/

Core modules + adapter implementations.

train.js

Offline training and learning pipeline.

bin/aiwaf.js

Operational CLI command surface.

resources/model.json

Default file-backed model artifact.

utils/db.js

SQLite Knex connection management.

Runtime Artifacts

  • aiwaf.sqlite (default SQLite DB)
  • logs/aiwaf-requests.jsonl
  • logs/aiwaf-requests.csv
  • logs/storage/*.csv (fallback stores)
