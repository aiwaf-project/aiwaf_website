How AIWAF works: system architecture

Native Python build

Run these commands in a virtual environment from the monorepo root. Stage the canonical README and LICENSE before changing directory:

cp README.md rust/README.md
cp LICENSE rust/LICENSE
python -m pip install maturin
cd rust
maturin develop
cd ..
pytest -q rust/tests/test_python_api.py

PowerShell users can use Copy-Item README.md rust/README.md and Copy-Item LICENSE rust/LICENSE for staging. These generated package-local assets are ignored by Git.

Rust core and WASM

cargo test --manifest-path rust/Cargo.toml --locked -p aiwaf_core
cd rust/crates/aiwaf_wasm
wasm-pack test --node
wasm-pack build --release --target bundler
cd ../..
python scripts/patch_wasm_pkg.py
cp ../LICENSE crates/aiwaf_wasm/pkg/LICENSE

PowerShell can replace the final cp with Copy-Item. Browser applications require a bundler that understands WebAssembly assets; initialize the WASM module before calling its exports.

Release manifests

  • PyPI: rust/pyproject.toml and rust/Cargo.toml, rust-v0.2.1, rust-publish.yml.
  • npm: rust/crates/aiwaf_wasm/Cargo.toml, wasm-v0.2.1, wasm-publish.yml.
  • PyO3 uses ABI3 wheels for Python 3.8 and newer, exporting aiwaf_rust.

Verification

Confirm import aiwaf_rust works in the interpreter used by the application. Validate model round trips through fit, to_json, from_json, and predict. Python selects available Rust capabilities automatically and falls back when unavailable. WASM performance depends on batch size and conversion cost.
