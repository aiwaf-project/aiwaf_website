Packaging, Troubleshooting, Validation

9. Build, Package, And Publish Notes

Python wheels/sdist

  • Build backend is maturin (pyproject.toml).
  • Module name is aiwaf_rust.
  • Uses PyO3 abi3-py38 compatibility mode for broad wheel support.

WASM npm package

  • Crate: crates/aiwaf_wasm
  • Build output: crates/aiwaf_wasm/pkg
  • Packaging helpers: scripts/patch_wasm_pkg.py, scripts/normalize_wheel.py

10. Troubleshooting

  • ImportError after maturin develop: ensure active venv matches build interpreter.
  • PyO3 build mismatch: verify Python 3.8+ and local maturin install.
  • WASM runtime errors: ensure await init() runs before calling exports.
  • Header false positives: verify header key normalization and required-header config.

11. Validation Checklist

  • Python import works: import aiwaf_rust.
  • Python tests pass: pytest tests/test_python_api.py -q.
  • WASM builds: wasm-pack build --release --target bundler.
  • WASM tests pass: wasm-pack test --node.
  • Isolation forest roundtrip validated in both bindings: fit -> to_json -> from_json -> predict.
