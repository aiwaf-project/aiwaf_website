5. PyO3 (Python) Binding Functions

Header Validation

  • validate_headers(headers: dict) -> Optional[str]
  • validate_headers_with_config(headers: dict, required_headers: Optional[list[str]], min_score: Optional[int]) -> Optional[str]

Feature Extraction

  • extract_features(records: list[dict], static_keywords: list[str]) -> list[dict]
  • extract_features_batch_with_state(records: list[dict], static_keywords: list[str], state: Optional[dict]) -> dict
  • finalize_feature_state(static_keywords: list[str], state: Optional[dict]) -> dict

Recent Behavior Analysis

  • analyze_recent_behavior(entries: list[dict], static_keywords: list[str]) -> Optional[dict]

IsolationForest (PyO3)

  • Constructor supports n_estimators, max_samples, contamination, max_features, bootstrap, n_jobs (ignored), random_state, verbose, warm_start.
  • Methods: fit, retrain, anomaly_score, is_anomaly, score_samples, decision_function, predict, to_json, from_json.

6. Isolation Forest Internals And Semantics

  • Core implementation in crates/aiwaf_core/src/lib.rs.
  • fit resets trees unless warm-start append is enabled.
  • retrain temporarily forces warm-start append behavior.
  • anomaly_score: higher means more anomalous.
  • score_samples: higher means more normal (sklearn-aligned direction).
  • decision_function = score_samples - offset_.
  • predict returns 1 (inlier) and -1 (outlier).
  • Contamination "auto" keeps offset_ = -0.5; fixed contamination computes percentile-based offset.

7. WASM Binding Functions

  • validate_headers, validate_headers_with_config

  • new(config?), fit, retrain, anomaly_score, is_anomaly, score_samples, decision_function, predict, to_json, from_json

Header Handling Notes

  • WASM accepts JS object or Headers.
  • Auto-fills user-agent from navigator.userAgent when absent.
  • Core still expects normalized HTTP_* style names internally.

8. Integration Patterns

Python service pattern

  1. Build normalized request dict.
  2. Run header validation early; block on non-None reason.
  3. Build feature records and update state incrementally.
  4. Score with IsolationForest and combine with rule outcomes.

JS/browser WASM pattern

  1. await init() at startup.
  2. Use wasm exports in request/event pipeline.
  3. Persist forest/state with to_json() as needed.

Python ↔ WASM portability

State JSON shapes differ across bindings. Use an explicit canonical transport schema and mapping adapters, with roundtrip tests.
