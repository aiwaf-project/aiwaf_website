Koa Setup

{% include '_docs_source.html' %}

Install

npm install aiwaf

Install the framework dependencies used by your existing application. The Node middleware package is aiwaf; source code and package scripts live in the monorepo's js/ directory.

Register the adapter

const Koa = require('koa');
const bodyParser = require('koa-bodyparser');
const aiwaf = require('aiwaf');

const app = new Koa();
app.use(bodyParser());
app.use(aiwaf.koa({ AIWAF_MIDDLEWARES: ['auto'] }));
app.use(ctx => { ctx.body = { protected: true }; });
app.listen(3000);

Generate route policies

Generate a manifest after the application's routes are registered. Express applications can call aiwaf.generateExpressManifest(app, '.aiwaf/paths.json'). Other adapters expose aiwaf.generateFrameworkManifest(framework, app, outputPath, options) with framework-specific route extraction.

For a route list stored in routes.json, use the installed CLI:

npx aiwaf manifest --framework koa --routes routes.json --output .aiwaf/paths.json

Review the resulting manifest and repeat generation when routes change. Manifest generation complements AIWAF_MIDDLEWARES: ['auto'] and explicit AIWAF_PATH_RULES overrides.

WASMAIWAF_WASM_VALIDATION, AIWAF_WASM_VALIDATE_RECENT

AIWAF loads aiwaf-wasm when available and falls back to the JavaScript implementation when WASM initialization or conversion is not worthwhile. Small, object-heavy operations can be faster in JavaScript because crossing the JS/WASM boundary and serializing objects has a fixed cost. WASM is most useful for sufficiently large feature batches and model scoring workloads.

Operate the installed package

npx aiwaf --help
npx aiwaf status
npx aiwaf list blacklist
npx aiwaf model info

For offline training from a source checkout:

cd aiwaf/js
AIWAF_ACCESS_LOG=/path/to/access.log npm run train

PowerShell users can set $env:AIWAF_ACCESS_LOG = '/path/to/access.log' before npm run train. Application installs do not inherit the package's npm scripts; use the installed CLI or the source checkout as appropriate.

Verify and deploy

Test normal routes, narrowly scoped exemptions, configured header policy, and rate-limit behavior in staging. Persist logs and model artifacts and schedule training after traffic volume thresholds are met. In-memory enforcement is process-local; use Redis or another shared cache when rate limits must span workers.
