AIWAF-JS End-To-End Setup Guide

1. What This Guide Is

End-to-end setup manual for running aiwaf-js in production Node.js applications. For internals, use PROJECT_DETAILED_REFERENCE.md.

  • Prerequisites and installation for app usage and repo development.
  • Framework integration for Express, Fastify, Hapi, Koa, NestJS, Next.js, AdonisJS, and Sails.
  • Baseline and production-oriented configuration, storage, model backend, training, and verification.
  • Optional WASM/GeoIP/Redis enablement plus troubleshooting and validation playbooks.

2. Prerequisites

Runtime

  • Node.js 18+ recommended.
  • npm 9+ recommended.
  • Supported app frameworks: Express, Fastify, Hapi, Koa, NestJS, Next.js API routes, AdonisJS, Sails.js.

System Dependencies

  • Build tooling required by sqlite3 for your OS.
  • Writable filesystem paths for aiwaf.sqlite, logs/, and resources/model.json if file model storage is used.

Production Recommendations

  • Access logs from reverse proxy/app layer.
  • Persistent volume for DB/log/model artifacts.
  • Scheduled training run (train.js) at least daily.

3. Installation Paths

# Application install
npm install aiwaf-js

# Local development
npm install

# Optional features
npm install aiwaf-wasm
npm install maxmind

Redis integration is enabled by setting REDIS_URL or AIWAF_REDIS_URL.

4. Core Configuration Concepts

Config is normalized from middleware options, optional AIWAF_SETTINGS, and environment variables.

  • Rate: AIWAF_RATE_WINDOW, AIWAF_RATE_MAX, AIWAF_RATE_FLOOD
  • Exemptions: AIWAF_EXEMPT_PATHS, AIWAF_EXEMPT_IPS, AIWAF_ALLOWED_PATH_KEYWORDS, AIWAF_EXEMPT_KEYWORDS, AIWAF_EXEMPTIONS_DB
  • Headers: AIWAF_HEADER_VALIDATION, AIWAF_REQUIRED_HEADERS, AIWAF_HEADER_QUALITY_MIN_SCORE, size/count caps
  • Geo: AIWAF_GEO_BLOCK_ENABLED, country allow/block sets, AIWAF_GEO_MMDB_PATH
  • Logging/training: middleware logging toggles + train thresholds + keyword learning flags
  • Model: AIWAF_MODEL_STORAGE, AIWAF_MODEL_PATH, fallback/cache settings
  • WASM: AIWAF_WASM_VALIDATION, header/recent toggles

5. Express Setup (Primary Path)

Basic Wiring

const express = require('express');
const aiwaf = require('aiwaf-js');

const app = express();
app.use(express.json());

app.use(aiwaf({
  staticKeywords: ['.php', '.env', '.git'],
  dynamicTopN: 10,
  WINDOW_SEC: 10,
  MAX_REQ: 20,
  FLOOD_REQ: 40,
  HONEYPOT_FIELD: 'hp_field',
  AIWAF_HEADER_VALIDATION: true,
  AIWAF_METHOD_POLICY_ENABLED: true,
  AIWAF_ALLOWED_METHODS: ['GET', 'POST', 'HEAD', 'OPTIONS']
}));

app.get('/health', (req, res) => res.json({ ok: true }));
app.listen(3000);

Middleware Order Guidance

  • Body parser before AIWAF when honeypot/content checks require parsed body.
  • Place AIWAF early to block before expensive downstream handlers.
  • Keep known-safe endpoints in exemptions (health/static/webhooks as needed).

Production Baseline Env

AIWAF_MIDDLEWARE_LOGGING=true
AIWAF_MIDDLEWARE_LOG_DB=true
AIWAF_MIDDLEWARE_LOG_CSV=true
AIWAF_RATE_WINDOW=10
AIWAF_RATE_MAX=60
AIWAF_RATE_FLOOD=120
AIWAF_HEADER_VALIDATION=true
AIWAF_HEADER_QUALITY_MIN_SCORE=3
AIWAF_EXEMPT_PATHS=/health,/favicon.ico,/robots.txt,/static/
AIWAF_EXEMPTIONS_DB=true

6. Other Framework Setup

Fastify

const fastify = require('fastify')();
const aiwaf = require('aiwaf-js');

fastify.register(aiwaf.fastify, {
  WINDOW_SEC: 10,
  MAX_REQ: 20,
  FLOOD_REQ: 40,
  AIWAF_HEADER_VALIDATION: true
});

Hapi

await server.register({
  plugin: aiwaf.hapi,
  options: { WINDOW_SEC: 10, MAX_REQ: 20, FLOOD_REQ: 40 }
});

Koa

app.use(bodyParser());
app.use(aiwaf.koa({ AIWAF_HEADER_VALIDATION: true }));

NestJS

// Express adapter
consumer.apply(aiwaf.nest({ AIWAF_HEADER_VALIDATION: true })).forRoutes('*');

// Fastify adapter
await app.register(aiwaf.fastify, { AIWAF_HEADER_VALIDATION: true });

Next.js / AdonisJS / Sails

// Next.js
export default aiwaf.next(handler, { AIWAF_HEADER_VALIDATION: true });

// Adonis
() => aiwaf.adonis({ AIWAF_HEADER_VALIDATION: true })

// Sails
aiwaf.sails({ AIWAF_HEADER_VALIDATION: true })

7-12. Storage, Training, CLI, Optional Features

Storage And Persistence

  • Default SQLite DB at ./aiwaf.sqlite, lazy table creation.
  • Managed tables: blocked/exemptions/geo/request logs/dynamic keywords/model artifacts.
  • CSV fallback under logs/storage/ if DB calls fail.
  • Model storage: file, db, or cache.

Training Setup

npm run train

NODE_LOG_PATH=/var/log/nginx/access.log
NODE_LOG_GLOB='/var/log/nginx/access.log.*'
AIWAF_MIN_TRAIN_LOGS=50
AIWAF_MIN_AI_LOGS=10000
AIWAF_FORCE_AI_TRAINING=false
AIWAF_ENABLE_KEYWORD_LEARNING=true

Training source priority: access logs, middleware JSONL, middleware CSV, DB request logs.

CLI Operations

npm run aiwaf -- <command>
# or
node bin/aiwaf.js <command>
  • List: blacklist/exemptions/geo/request logs/dynamic keywords/model info
  • Add/remove exemptions, geo block/unblock
  • Clear blacklist/request logs/dynamic keywords
  • train and diagnose <ip>

Optional WASM

npm install aiwaf-wasm
AIWAF_WASM_VALIDATION=true
AIWAF_WASM_HEADER_VALIDATION=true
AIWAF_WASM_VALIDATE_RECENT=false

Optional GeoIP

npm install maxmind

AIWAF_GEO_BLOCK_COUNTRIES=CN,RU
# or allowlist mode
AIWAF_GEO_ALLOW_COUNTRIES=US,CA

Optional Redis

13-16. Production Checklist, Validation, Troubleshooting, Contributor Setup

Production Baseline Checklist

  • [ ] Middleware enabled and app startup verified.
  • [ ] Body parser ordering confirmed where required.
  • [ ] Exempt paths configured for health/static/known-safe callbacks.
  • [ ] Rate and header policies tuned with real traffic profile.
  • [ ] Middleware logging persisted.
  • [ ] Training scheduled and validated.
  • [ ] Intentional block event verified in staging.
  • [ ] CLI operations validated (list, diagnose, train).

Validation Playbook

  1. Smoke: /health and static routes pass; suspicious probe path blocks.
  2. Rate limits: burst non-exempt endpoint and observe 429/403 behavior.
  3. Header checks: low-quality headers trigger expected validation behavior.
  4. Training: verify source detection and npm run train output.

Troubleshooting Highlights

  • sqlite3 build failure: install platform-native build tools and reinstall deps.
  • DB errors: ensure write permissions for DB/working directory.
  • No training data: verify log paths/globs and enable middleware logging fallback.
  • Model load issues: train and verify model storage path/backend permissions.
  • False positives: tune exemptions/allowed keywords and thresholds gradually.
  • Geo issues: verify maxmind, MMDB path, ISO country codes, and proxy IP resolution.
