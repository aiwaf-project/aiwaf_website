How it works

  1. RunnerSends normal requests, simulated clients, and payloads.
  2. AIWAF proxyApplies runtime controls before forwarding.
  3. RedisShares supported state under isolated namespaces.
  4. ApplicationJuice Shop supplies a vulnerable baseline; the reference fixture supplies outcome assertions.

The sandbox repository owns Compose, proxies, fixtures, and runners. BuildKit fetches AIWAF commit 843a35f4fd48b4ef565e3c1ec8a42db9b1c41946. No adjacent local AIWAF checkout is needed. Use a sandbox revision containing these source-context changes.

That commit builds Python/JavaScript 1.1.1 and Java 1.3.2. Source versions do not establish registry publication. PHP remains a separate Composer integration, excluded from the current fifteen-runtime validation.

Evaluate your build

Generate reports for the source commit, container images, and configuration you are testing. Run the validation workflow to check source versions, normal traffic, SQL login outcomes, TLS, failures, and dependencies.

Passing implemented scenarios does not close an entire OWASP category. See coverage and assessment boundaries before making a security claim.
