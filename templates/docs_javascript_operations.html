Ops And Release

CLI, Config, Testing, Packaging

CLI And Operational Commands (bin/aiwaf.js)

npm run aiwaf -- <command>
# or
node bin/aiwaf.js <command>

Supported Commands

  • list blacklist, list exemptions, list geo
  • list request-logs [limit], list dynamic-keywords [limit], list model-info
  • add/remove ip-exemption, add/remove path-exemption
  • geo block/unblock/summary
  • clear blacklist, clear request-logs, clear dynamic-keywords
  • train, diagnose <ip>

Output is JSON-first for script-friendly automation. train delegates to node train.js.

Configuration Model (AIWAF_*)

Settings are normalized by lib/settingsCompat.js from middleware options, legacy nested settings, and environment variables.

High-Impact Groups

  • Rate limiting: AIWAF_RATE_WINDOW, AIWAF_RATE_MAX, AIWAF_RATE_FLOOD
  • Honeypot/method policy: AIWAF_MIN_FORM_TIME, AIWAF_MAX_PAGE_TIME, AIWAF_ALLOWED_METHODS, AIWAF_METHOD_POLICY_ENABLED
  • Exemptions: AIWAF_EXEMPT_PATHS, AIWAF_EXEMPT_IPS, AIWAF_ALLOWED_PATH_KEYWORDS, AIWAF_EXEMPT_KEYWORDS, AIWAF_EXEMPTIONS_DB
  • Header validation: AIWAF_HEADER_VALIDATION, AIWAF_REQUIRED_HEADERS, AIWAF_HEADER_QUALITY_MIN_SCORE, and header size/count limits
  • Geo controls: AIWAF_GEO_BLOCK_ENABLED, geo allow/block country sets, MMDB path, cache controls
  • Model/training: storage/path/fallback/cache options + AI training threshold flags
  • Logging controls: JSONL/CSV/DB toggles and paths
  • WASM toggles: AIWAF_WASM_VALIDATION, header/recent validation flags

Request Lifecycle (Simplified)

  1. Request enters unified middleware.
  2. Exemption checks evaluate IP/path bypass.
  3. Header and optional WASM validations run.
  4. Geo checks run.
  5. Honeypot/timing checks run.
  6. Rate limiter records and enforces thresholds.
  7. Static + dynamic keyword checks run.
  8. UUID tamper checks run.
  9. Unknown-route anomaly checks run when model is sufficiently trained.
  10. Blocked requests are denied and logged; all requests can be logged to JSONL/CSV/DB.

Testing And Local Development

  • Node.js LTS, npm, and sqlite3 compatibility required.
  • Common commands:
npm install
npm test
npm run train
npm run aiwaf -- help
npm run perf:wasm
npm run test:wasm-real

Jest notes: --runInBand, teardown via test/jest.teardown.js, and forceExit: true.

Packaging And Release Surface

  • Published files include index.js, bin/, lib/, resources/, utils/, train.js, docs/license files.
  • Published CLI binary: aiwaf -> bin/aiwaf.js.

Operational Notes

  • Middleware order is security-critical and false-positive-sensitive.
  • Anomaly model failures should not break request handling.
  • Geo lookups can run via MMDB or header fallback.
  • Store modules are defensive: DB failures should not disable core protections.
  • Unknown-route anomaly checks stay conservative until model training is sufficient.
