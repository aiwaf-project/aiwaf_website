How AIWAF works: system architecture

Legacy CLI and training from source

The commands in this section operate on legacy Node stores. They do not import or manage the native engine's dedicated CSV event files.

cd js

AIWAF_ACCESS_LOG=/path/to/access.log npm run train
npm run aiwaf -- status
npm run aiwaf -- list blacklist
npm run aiwaf -- add blacklist 203.0.113.9 "manual block"
npm run aiwaf -- add ip-exemption 203.0.113.10 "trusted monitor"
npm run aiwaf -- geo summary
npm run aiwaf -- model info
npm run aiwaf -- export aiwaf-export.json

Use Redis or another shared cache for consistent rate limiting across multiple Node processes. Without shared state, the in-memory fallback is process-local.

The npm run commands above use the package scripts in the monorepo's js/ directory. In an application that installed the package, use the installed binary, for example npx aiwaf status or npx aiwaf --help.

AIWAF loads aiwaf-wasm when available and falls back to the JavaScript implementation when WASM initialization or conversion is not worthwhile. Small, object-heavy operations can be faster in JavaScript because crossing the JS/WASM boundary and serializing objects has a fixed cost. WASM is most useful for sufficiently large feature batches and model scoring workloads.

Packaging

The package manifest is js/package.json; the CLI entry is js/bin/aiwaf.js. Release tags use js-v<version> and the npm-publish.yml workflow. The root README and LICENSE are staged into package artifacts by release automation.

Request parsing and cache failures

For custom Node HTTP servers or middleware registered before a framework parser, call aiwaf.bodyParser() before AIWAF and before forwarding requests. It parses JSON and URL-encoded bodies, retains original forwarding bytes, and rejects oversized bodies (default 64 KiB). Fastify/Hapi integrations must enforce AIWAF after body parsing and before their proxy handler.

Redis rate-cache failures return generic HTTP 503. AIWAF_RATE_CACHE_FAILURE_MODE defaults to 'closed'; explicitly choosing 'open' allows requests during cache failures. The new filesystem CSV transactions and retained training handles are Python/PyO3 capabilities; installing WASM does not migrate Node middleware/storage to that implementation.

Native deployment and benchmarking

Native mode: Node source candidate aiwaf 1.1.4 declares aiwaf-wasm ^0.2.4. Explicit native registration validates NativeRequestPipeline at startup; missing or incompatible support is an error. There is no JavaScript policy fallback for this engine. Installing the dependency does not switch an existing legacy middleware chain.

Build/install the matching WASM companion first, await initialization, verify diagnostics().native and diagnostics().model, and test normal routes, unknown PHP paths and nested SQL bodies. Use setModel(model) to replace the fitted Rust snapshot or restart. The legacy trainer/log stores are separate from the native event files; do not assume an automatic import.

Run npm run test:native from js/ in the source checkout. node scripts/benchmark_js_pipeline.js compares full HTTP requests against bare Express, with AI off/on and actual inference counters. Server samples include synchronous finalization/logging, and overhead subtracts the framework-only baseline. Legacy SQLite/JSONL and native Rust/CSV have different persistence semantics, so comparisons are integration results rather than pure language speedups.

Stop traffic and wait for in-flight responses before close(). Model/rate/honeypot/history state is local; persisted blocks/keywords only reload on reconstruction. Publication must make the compatible WASM API available before users enable native mode.

Read the native lifecycle, configuration, deployment and measurements, and migration.

Measured Node request overhead

Windows x64, Node v22.18.0, Express 4.22.1, built WASM 0.2.2. Three alternating runs of 300 requests per mode, one keep-alive client. 80% GET / 20% JSON POST with 30 fields; 1,000 blacklist entries; all eight stages selected; memory rate/form state. Native AI uses a seeded 100-tree forest fitted to 200 rows, with one inference per measured/warm-up request verified by counters.

Native execution and actual inference counters were verified; all 3,600 measured requests returned 200. Protected SQL/PHP probes returned 403. Reproduce from the source checkout with scripts/benchmark_js_pipeline.js.

Dependency security and reproducible checks

The source lockfile uses Jest 30.5.2, Fastify 5.12.7, and patched NestJS 11 dependencies (the validated install resolved 11.2.7). The direct glob dependency is 13.0.6. Targeted overrides update qs and the NYC loader's YAML dependency; old global parser overrides have been removed. Framework packages in devDependencies support adapter testing; they do not select the framework for an installed application.

cd js
npm ci
npm audit
npm run test:coverage
npm run test:wasm
npm run test:native

The repository's Jest tests use generated CommonJS WASM bindings through AIWAF_NATIVE_TEST_MODULE. Release CI builds that fixture from rust/crates/aiwaf_wasm and runs real installed-WASM checks separately. Jest also transforms the ESM cookie dependency used by Fastify's injection client so the suite works on Node 22.

Earlier dependency validation on 13 October 2026 passed 227 tests across 63 suites, with coverage thresholds met, plus real WASM and native framework transport checks. npm ci and the full npm audit reported zero known vulnerabilities for that lockfile. The release workflow audits production and development dependencies. Rerun the audit after dependency changes; this result describes the tested tree and advisory database at that time.

Upstream deprecation warnings remain for SQLite's prebuild-install and coverage tooling's glob 10 dependency. Deprecation notices and blocked optional install scripts are separate from audit findings. The repository permits SQLite's install script; the tested installation did not require enabling every optional postinstall script.

The latency figures above were measured before this dependency update. They have not been remeasured with the patched tree.
