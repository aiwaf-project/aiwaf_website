How AIWAF works: system architecture

Where is the source code?

Python, Node.js, Rust/WASM, and Java are in the AIWAF monorepo. The root README is authoritative, and each package has its own version and release tag.

What do I install for Node.js?

Use npm install aiwaf and require('aiwaf'). See the Node.js setup guide.

Is PHP included?

The current monorepo has no PHP implementation or PHP release workflow. Existing PHP pages are retained as legacy reference and are not current setup guidance.

Is Rust required for Python?

No. Install aiwaf[rust] for native acceleration. Installed capabilities are selected automatically, with Python fallback when unavailable. Version 1.0.8 requires aiwaf-rust>=0.2.1 for this extra.

Can I reuse old pickle or joblib models?

Current Python model persistence uses JSON. Regenerate executable object artifacts through the current trainer. Java supports Python Rust-model JSON state and restricted legacy signed Java artifacts. JavaScript model implementations remain language-native; do not assume every runtime can exchange models.

Does an in-memory backend share protection across workers?

In-memory state is process-local. Configure shared storage where consistent multi-worker enforcement is required. Java 1.3.0 supports standalone Redis with atomic enforcement, failure policies, bounded waits, and schema compatibility checks.

What are the hardware requirements?

AIWAF does not prescribe the previously listed RAM, AVX2, or disk requirements. Use a runtime compatible with the package dependencies and size the deployment for traffic, logging, training, and model workloads. Java targets Java 17; Python metadata declares 3.8 or newer, with newer requirements possible from selected dependencies.

How does training update protection?

Offline training parses configured logs, extracts six features, trains after volume thresholds are met, and refreshes learned keywords while excluding legitimate routes. Schedule training in your deployment; the repo does not promise a real-time external threat-intelligence feed.

How do I investigate false positives?

Review request logs, trusted-proxy handling, header requirements, rate limits, and path policies. Use narrowly scoped route exemptions and representative staging requests. Check framework CLI status and verify the application object imported for route discovery.
