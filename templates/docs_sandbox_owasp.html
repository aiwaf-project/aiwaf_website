OWASP Top 10 coverage

The OWASP Top 10:2025 describes broad application risks. The sandbox combines request observations, confirmed SQL outcomes, reference-application rules, TLS checks and dependency findings. Those are different kinds of evidence.

All implemented scenario checks outside the recorded A03 advisory failures passed in the earlier assessment. This means the tested scenarios passed, not that every other category is closed. The fresh GitHub run repeated source/build, smoke and SQL checks only.

What the reference fixture proves

The fixture is separate from Juice Shop. It uses two users, independently salted PBKDF2-SHA256 hashes with 600,000 iterations, random sessions, test-only reset/MFA controls, isolated inventory and HMAC-protected data. The Compose service starts securely; regression tests also use deliberately broken fixture modes to verify that assertions detect failures.

Each check validates response fields and side effects, not merely an HTTP denial. Per-run state is cleaned afterward; fixture signing keys/state are ephemeral. The default control credential is sandbox-assessment-only; AIWAF_ASSESSMENT_TOKEN overrides it for both Compose and runner. Tokens/passwords are excluded from reports. Reference rules demonstrate an assessment technique, not AIWAF implementations of identity/business policies.

Recorded supply-chain findings

The October 9 scan before the GitHub rebuild covered fifteen non-PHP images with pinned Grype 0.120.0. Every image had zero critical matches. All eight Node and all three Python images each retained 55 high matches. All four Java images had zero high matches, with medium/lower findings retained.

Across the eleven affected images, the reports record 586 high matches marked wont-fix and 19 marked not-fixed, with no listed fix versions. These counts repeat shared packages across images; they are not 605 distinct exploitable vulnerabilities. The npm production audits separately returned zero findings.

A03 image checks remain failed while high/critical matches exist. Advisory matches require location and exploitability triage; findings are not suppressed. These historical scans do not certify the rebuilt GitHub images. Run assessment/scan_images.py again, retain database/scan timestamps and image IDs, and report current results.

How to describe the result

Use: “The implemented sandbox scenarios passed; A03 image advisories and the documented production-control gaps remain.” Avoid “OWASP certified,” “10/10 compliant,” or “all other OWASP categories closed.” Completion of the 375-case matrix establishes collection of observations without request errors, not universal exploit prevention.
