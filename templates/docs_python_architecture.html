Core Design

Architecture And Shared Layer

High-Level Architecture

  • Framework-agnostic core in aiwaf/core/*.
  • Adapters for Django, Flask, and FastAPI sharing common logic.
  • Storage abstraction with memory/file/CSV/DB options.
  • Training pipeline for feature extraction and anomaly model lifecycle.
  • Optional Rust backend for header validation and feature extraction acceleration.

Core Intent

  • Graceful degradation when optional dependencies are unavailable.
  • False-positive reduction via exemptions and route-aware heuristics.
  • Portable behavior across Python web frameworks.

Configuration Model

  • Modern flat settings/env keys: AIWAF_*.
  • Legacy nested AIWAF_SETTINGS compatibility mapping in Django.
  • Control domains: storage, AI thresholds, rate limits, exemptions, geo mode, header validation, model store, Rust toggle, path rules.

Storage Semantics

Runtime Backends

  • MemoryStorage: in-process key/value + cleanup.
  • FileStorage: JSON file via atomic temp-file replace.
  • CSVStorage: key/value storage over CSV.
  • DBStorage: SQLite key/value store.

Typed Stores

  • ExemptionStore, BlacklistStore, KeywordStore, GeoBlockStore.

Training And AI Lifecycle

The Python trainer coordinates a multi-stage pipeline across core logic modules like training.py and training_logic.py:

  1. Log Parsing: Extracts requests from configured sources (combined, common, CSV, JSON logs, or middleware fallbacks).
  2. Feature Extraction: Converts requests into a 6-dimensional feature vector for the Isolation Forest:
    • Path length
    • Keyword hits against known static lists
    • Status code bucket (mapping to 200/403/404/500 indices)
    • Response time
    • Burst count (10-second rolling window)
    • Per-IP 404 count
  3. Rust Acceleration: If AIWAF_USE_RUST=True, feature extraction and ML model persistence are accelerated via the aiwaf_rust backend. A JSON model artifact is persisted since object serialization (like pickle) is strictly disallowed for security reasons.
  4. Anomaly Model Training: Trains a 200-tree Isolation Forest when thresholds (AIWAF_MIN_AI_LOGS) permit, and filters anomalous predictions (e.g. enforcing at least some suspicious keywords or 404s) before issuing blocks.
  5. Keyword Learning: Extracts tokens from 4xx/5xx requests evaluated via is_malicious_context(). Matches indicators like ../, .env, wp-admin, eval, or extreme URL lengths/depths.
  6. Exemptions: Excludes legitimate/exempt keywords via get_default_legitimate_keywords() to drastically reduce false positives.

Execution Safeguards

  • Disable AI path when logs are insufficient (AIWAF_MIN_TRAIN_LOGS fallback).
  • Post-filter anomaly predictions before hard blocks to keep burst-only harmless traffic unblocked.
  • Fall back to keyword protections when AI dependencies or rust integrations are missing.

AST Static Analysis (aiwaf/core/api_detection.py)

AIWAF utilizes Python's built-in ast module to infer route capabilities statically, primarily used during manifest generation to correctly classify endpoints when framework metadata (like Django decorators) is missing.

  • Parsing: Source files are converted to an AST using ast.parse(source).
  • Traversal: Custom ast.NodeVisitor implementations (e.g., ApiDetectorVisitor) walk the tree to identify key signals.
  • Method Inference: Detects explicit HTTP methods by scanning decorator lists (e.g., @require_http_methods(['GET']) or FastAPI's @app.get()) and internal if request.method == 'POST' checks.
  • API Detection: Flags high api_score values when it detects JsonResponse returns, @api_view decorators, or serialization calls (json.dumps, pydantic models).
  • Auth Detection: Detects authentication paths by searching for calls to authenticate(), login(), or typical auth-centric functions like create_access_token.

Path Generation and Auto Middleware (aiwaf/core/path_manifest.py)

AIWAF intelligently generates optimized routing rules and toggles middleware autonomously by categorizing path intents.

  • Route Classification (classify_route): Interprets AST and framework metadata to group paths as api, form, admin, upload, static, or auth.
  • Auto Middleware Planning: Automatically modifies the protections array for the target path based on its category:
    • API Endpoints: Disables HTML honeypots, raises rate limits (120 req/min), and enforces JSON payloads.
    • Form/Auth Endpoints: Enables strict Honeypot timing and limits requests to 30 req/min.
    • Static Assets: Automatically suppresses AI anomaly scoring, honeypots, and header validations to maintain max performance.
  • Rule Compilation (compile_manifest_to_path_rules): Compiles these abstracted protections into standardized DISABLE and RATE_LIMIT path rules injected directly into the runtime adapters.

Detailed Middleware Execution Chain

Both Django and FastAPI adapters orchestrate a strict execution sequence. An example chain logic (as defined in aiwaf/django/middleware.py):

  1. Exception/Response Wrapper: JsonExceptionMiddleware ensures that if an API is blocked, the response is formatted as JSON instead of HTML.
  2. Geo Blocking: GeoBlockMiddleware rejects requests from blocked country codes early to save resources.
  3. IP & Keyword Blocking: IPAndKeywordBlockMiddleware enforces the static blacklist and dynamic keyword protections (exemption-aware).
  4. Rate Limiting: RateLimitMiddleware executes sliding-window checks (burst & flood controls) backed by memory or Redis.
  5. AI Anomaly: AIAnomalyMiddleware executes the ML IsolationForest checks on unknown routes.
  6. Honeypot: HoneypotTimingMiddleware checks GET-to-POST timing thresholds and form submission misuse.
  7. UUID Tamper: UUIDTamperMiddleware validates UUID integrity and 404-probing rates.
  8. Header Validation: HeaderValidationMiddleware scores the request headers against bot signatures.
  9. Logging (Post-Response): AIWAFLoggerMiddleware captures telemetry and writes JSONL/CSV lines for offline training if configured.

Security Subsystems

Header Validation

  • Required header resolution with method-aware overrides.
  • Suspicious UA and header-combination heuristics.
  • Caps on header bytes/count/value lengths.
  • Quality score model with optional Rust fast-path.

GeoIP And Country Blocking

  • Geo DB path: aiwaf/core/geolock/ipinfo_lite.mmdb.
  • Allowlist mode and blocklist mode supported.
  • Adapters add cache integration where available.

Exemptions And Path Rules

  • Path, IP, decorator, and persisted exemption layers.
  • Path rules can disable middleware or override rate limits.
