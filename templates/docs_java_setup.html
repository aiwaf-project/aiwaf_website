Comprehensive Setup

AIWAF-Java Comprehensive Setup Guide

1. Scope

  • Plain Java/Servlet and Spring application integration.
  • Local development, sandbox validation, and production rollout.
  • Request pipeline order, runtime persistence, AI anomaly behavior, model artifact compatibility, observability, and structured config compatibility.

2. Prerequisites

  • Required: Java 17+, Maven 3.9+.
  • Optional: Docker + Compose, mmdblookup, python-whois, system whois.
  • Runtime defaults: model path aiwaf-model.bin, storage backend/path via storageBackend/storageFilePath.

3. Install And Build

<dependency>
  <groupId>io.github.aiwaf-project</groupId>
  <artifactId>aiwaf-java</artifactId>
  <version>0.2.0</version>
</dependency>

mvn clean test
mvn clean package

4. Quick Start (Core Engine)

AiwafConfig config = new AiwafConfig();
config.headerValidationEnabled = true;
config.rateLimitEnabled = true;
config.storageBackend = "memory";

AiwafEngine engine = new AiwafEngine(config);
AiwafDecision decision = engine.evaluate(request);
if (!decision.allowed()) {
    // deny with decision.statusCode() and decision.reason()
}

5. Request Pipeline (Exact Order)

  1. Resolve PathRule and middleware overrides.
  2. Resolve path exemptions from config/store/geo-exempt sets.
  3. Resolve IP exemptions.
  4. Blacklist gate (403).
  5. Method allow-list gate (405).
  6. IP/keyword checks and contextual keyword learning.
  7. UUID tamper check.
  8. Honeypot timing checks (403/409).
  9. Header validation checks.
  10. Geo allow/block checks.
  11. Rate/flood checks (429).
  12. AI anomaly check.
  13. Allow decision.

6. Integration Components

  • Spring: AiwafFilter, AiwafInterceptor, AiwafRouteDecisions, and annotations.
  • Servlet: AiwafServletFilter with ServletRequestMapper and deny/allow flow.

7. Key Configuration Areas (AiwafConfig)

  • Middleware toggles, rate limits, exemptions, header policy, geo policy, method policy.
  • Keyword learning and route legitimacy hints.
  • AI model options: lazy/background load, threshold, behavior confirmation.
  • Observability + extended block context + storage backend/path.

8. Runtime Storage

RuntimeStorage.initialize(config.storageBackend, config.storageFilePath);
  • Backends: memory, file, csv.
  • Stores: exemptions, path exemptions, blacklist, keywords, geo blocks.

9. CLI + Validation

mvn -q -DskipTests exec:java -Dexec.mainClass=com.aiwaf.cli.AiwafConsole -Dexec.args="stats"
java -cp target/classes com.aiwaf.cli.AiwafConsole stats
mvn test

Use CoreCli for request/behavior analysis and replay fixtures.

10. Production Checklist

  • Set explicit AiwafConfig values for real traffic.
  • Use persistent storage when restart stability is required.
  • Tune rate/header/AI thresholds and confirmation gates.
  • Keep telemetry enabled during rollout and monitor counters/histograms.
  • Run sandbox + fixture replay validation in CI.
