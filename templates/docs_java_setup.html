Comprehensive Setup

AIWAF-Java Comprehensive Setup Guide

1. Prerequisites

  • Java 17+
  • Maven 3.9+
  • Optional Docker + Docker Compose for sandbox validation
  • Optional mmdblookup for GeoIP MMDB CLI lookup
  • Optional python-whois and system whois for CLI lookup operations

2. Install And Build

<dependency>
  <groupId>io.github.aiwaf-project</groupId>
  <artifactId>aiwaf-java</artifactId>
  <version>0.1.0</version>
</dependency>

mvn clean test
mvn clean package

3. Core Engine Quick Start

AiwafConfig config = new AiwafConfig();
config.headerValidationEnabled = true;
config.rateLimitEnabled = true;

AiwafEngine engine = new AiwafEngine(config);
AiwafDecision decision = engine.evaluate(request);
if (!decision.allowed()) {
    // deny using decision.statusCode() + decision.reason()
}

4. Spring Integration

  • com.aiwaf.spring.AiwafFilter
  • com.aiwaf.spring.AiwafInterceptor
  • com.aiwaf.spring.support.AiwafRouteDecisions
  • Annotations: @AiwafExempt, @AiwafExemptFrom, @AiwafOnly, @AiwafRequireProtection

Create one shared AiwafEngine and wire the filter/interceptor into your request chain.

5. Servlet Integration

  • com.aiwaf.servlet.AiwafServletFilter
  • Maps HttpServletRequest to AiwafRequest via ServletRequestMapper
  • Denied requests return sendError(status, reason)

6. Runtime Storage Backends

RuntimeStorage.initialize("memory", null);
RuntimeStorage.initialize("file", "aiwaf_data.bin");
RuntimeStorage.initialize("csv", "aiwaf_data.csv");
  • memory default in-process backend
  • file Java-serialized map for persistence
  • csv CSV-backed persistence path

7. Admin CLI

mvn -q -DskipTests exec:java -Dexec.mainClass=com.aiwaf.cli.AiwafConsole -Dexec.args="stats"
java -cp target/classes com.aiwaf.cli.AiwafConsole stats
  • stats, list ..., add ..., remove ...
  • export, import, reset, whois

8. Production Checklist

  1. Initialize persistent runtime storage during app bootstrap.
  2. Tune AiwafConfig controls (header, rate, geo, exemptions) per environment.
  3. Set path rules for high-volume or special endpoints.
  4. Run mvn clean test and sandbox verification before release.
  5. Capture and monitor deny telemetry for threshold refinement.
