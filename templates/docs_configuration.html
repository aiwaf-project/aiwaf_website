Configuration is adapter-specific. Use the names accepted by your runtime, and apply settings before registering protection. The tables below describe source defaults; they do not guarantee that a middleware is selected or that a route is protected.

Flask and Django flat settings

The nested Python table below is the shared configuration manager, primarily exposed through FastAPI. It is not the Flask/Django constructor signature. Their important flat names include AIWAF_RATE_WINDOW (seconds), AIWAF_RATE_MAX and AIWAF_RATE_FLOOD (integer counts), AIWAF_EXEMPT_PATHS (path list), AIWAF_PATH_RULES (rule list), AIWAF_GEO_BLOCK_COUNTRIES and AIWAF_GEO_ALLOW_COUNTRIES (country-code lists), and AIWAF_MODEL_PATH (path). Consult each adapter's settings guide for the full flat surface.

# Flask: set values before middleware registration.
app.config.update(
    AIWAF_RATE_WINDOW=10,
    AIWAF_RATE_MAX=20,
    AIWAF_RATE_FLOOD=40,
    AIWAF_RATE_CACHE_BACKEND='redis',
    AIWAF_REDIS_URL='redis://localhost:6379/0',
    AIWAF_RATE_CACHE_KEY_PREFIX='my-service:rate:',
)
AIWAF(app, middlewares=['all'])

Flask's rate middleware defaults to 10 seconds, 20 requests, and flood threshold 40. The website overrides these values in app.py. Node's normalized defaults are 60 seconds, 100 requests, and flood threshold 200. Do not use website thresholds as universal package defaults.

FastAPI nested options

from fastapi import FastAPI
from aiwaf.fast import AIWAF

app = FastAPI()
AIWAF(app, middlewares=['all'],
      rate_limiting={'window_seconds': 10, 'max_requests': 20,
                     'flood_threshold': 40, 'cache_backend': 'redis',
                     'redis_url': 'redis://localhost:6379/0',
                     'cache_key_prefix': 'my-service:rate:'})

The shared environment loader recognizes names such as AIWAF_RATE_WINDOW_SECONDS and AIWAF_RATE_MAX_REQUESTS. Those differ from the Flask/Django flat names. Boolean strings accept true, 1, yes, and on as true; list mappings split comma-separated values. File lists use JSON arrays. Review the environment map before assuming a setting is supported.

Middleware, route policy, and exemptions

all selects the canonical middleware set. auto omits checks based on detected application signals. Explicitly disabled middleware and route exemptions can bypass checks even when their configuration says enabled. Regenerate route manifests after route changes and inspect the selected middleware at runtime.

Default exemptions differ. Django includes administrative/login paths; Flask includes health, crawler, static and asset paths. Private-address behavior also differs from an explicit trusted-client whitelist. Review Python default exemption lists and the policy lifecycle before interpreting a successful local request as a public-client test.

Configure forwarding-header handling with the actual deployment topology. Java exposes trustedProxyCidrs and maxForwardedForEntries. Python and Node extraction use adapter-specific rules; these Java options are not portable knobs. Have the outer proxy overwrite untrusted client forwarding headers, and compare observed client addresses with the intended public client.

Multiple workers and storage

Persistent blacklist files, model storage, logs, and rate counters have separate ownership. A CSV blacklist does not share every in-memory counter. Flask/FastAPI use separate rate-cache settings; install the Redis client required by the selected backend. Flask rejects invalid Redis configuration at initialization. Python rate-cache failures produce generic HTTP 503 responses, and FastAPI does not silently select a process-local cache. Verify repeated requests across workers and inspect backend diagnostics.

Node accepts a shared cache implementation; its fallback is process-local. Java Redis shares enforcement state within storageKeyPrefix, supports standalone mode, and defaults to fail_closed. Use the same namespace only for intentionally shared policy/state, and review schema compatibility before mixed-version deployments.

Source default tables

The Python table includes every leaf returned by the shared manager. The Node table includes normalized options, not every raw option consumed by individual modules (for example cache/WASM settings). The Java table includes public AiwafConfig field initializers. Disabled middleware can leave a setting inactive. These tables are a source snapshot, not your effective live configuration.

Legacy adapter native CSV settings

These uppercase settings apply to the retained legacy adapters. The explicit native pipeline uses a separate lowercase profile.

SettingDefault and scope
AIWAF_USE_RUST, AIWAF_RUST_CSVEnabled by default for supported Flask/Django native CSV dispatch. Set either application setting to False to disable it. FastAPI training also honors these application options.
AIWAF_RUST_CSV=false environment variableDisables shared native dispatch outside Flask/Django application contexts. Configured framework settings take precedence over this environment fallback.
AIWAF_CSV_REQUEST_CACHEFlask defaults to True. Reuses exemptions within a request while rechecking file metadata/configuration; does not cache rate mutations or blacklist expiry decisions.
AIWAF_CSV_LOG_FSYNCFlask CSV logging defaults to False. True synchronizes each row to disk. Changed policy-state writes still synchronize.
AIWAF_RUST_ISO_DATES=1Optional environment flag for native ISO timestamp parsing. Python's faster C ISO parser remains the default.
AIWAF_RATE_CACHE_BACKEND='csv'Explicit Flask selection of persistent shared rate buckets. Memory remains the default. Requires native support; unavailable/disabled native support returns HTTP 503.
AIWAF_RATE_CSV_PATHOptional Flask path; defaults to rate_buckets.csv under AIWAF_DATA_DIR.
# Set before AIWAF(app).
app.config.update(AIWAF_USE_CSV=True, AIWAF_USE_RUST=True,
                  AIWAF_RUST_CSV=True, AIWAF_CSV_LOG_FSYNC=False)
# Optional, costlier than process memory: shared CSV rate counters.
app.config['AIWAF_RATE_CACHE_BACKEND'] = 'csv'

CSV buckets trim the request window, consume a request, evaluate thresholds, and persist TTL under one native transaction. Rewriting and syncing on every request can cost more than Redis or memory. A CSV blacklist alone does not select this rate backend.

Native pipeline profile (Python 1.1.6)

Release candidate: this page documents Python 1.1.6 and Rust/Python 0.2.5 in the current source checkout. Source versions do not establish registry availability. Python 1.1.6 requires aiwaf-rust>=0.2.5; framework dependencies remain extras.

Pass a dedicated lowercase config dictionary in Flask/FastAPI, or use AIWAF_CSV_PIPELINE in Django. Existing uppercase settings, nested AIWAFConfig dictionaries, PATH_RULES, manifests and custom policy callbacks are not merged into this profile. Unknown keys fail initialization. The profile is immutable; construct a new engine and reload workers to change it. Legacy Rust-disable flags do not select a Python fallback for this engine.

Node native pipeline profile

Native mode: Node source candidate aiwaf 1.1.4 declares aiwaf-wasm ^0.2.4. Explicit native registration validates NativeRequestPipeline at startup; missing or incompatible support is an error. There is no JavaScript policy fallback for this engine. Installing the dependency does not switch an existing legacy middleware chain.

Adapter options: profile, dataDir, logPath, logFsync, persistBlocks, model, synchronous countryLookup/authenticated/routeExists, and onError. Unknown options fail startup. The profile is immutable and accepts lowercase keys only; reconstruct/reload to change it.

This does not provide live cross-worker sharing; use separate files per worker. Legacy Redis/ORM/custom callbacks, manifests and uppercase settings are not imported.
