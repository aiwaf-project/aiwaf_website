Configuration Reference

{% include '_docs_source.html' %}

Configuration is adapter-specific. Use the names accepted by your runtime, and apply settings before registering protection. The tables below describe source defaults; they do not guarantee that a middleware is selected or that a route is protected.

Inputs and precedence

FlaskFlat app.config['AIWAF_*'] settings; constructor middleware selectionLoad application configuration before AIWAF(app). A shell variable does not automatically become Flask app.config. The middleware reads adapter settings and its own defaults.

FastAPINested constructor options or AIWAFConfigDefaults, then JSON file, then recognized environment mappings, then explicit constructor overrides. If a config object is supplied, it is used directly rather than rebuilding from config_file/overrides.

Rust/WASMArguments to primitive bindingsThese bindings are not a framework configuration loader. Host adapters control middleware, policy, storage, and proxy handling.

Flask and Django flat settings

The nested Python table below is the shared configuration manager, primarily exposed through FastAPI. It is not the Flask/Django constructor signature. Their important flat names include AIWAF_RATE_WINDOW (seconds), AIWAF_RATE_MAX and AIWAF_RATE_FLOOD (integer counts), AIWAF_EXEMPT_PATHS (path list), AIWAF_PATH_RULES (rule list), AIWAF_GEO_BLOCK_COUNTRIES and AIWAF_GEO_ALLOW_COUNTRIES (country-code lists), and AIWAF_MODEL_PATH (path). Consult each adapter's settings guide for the full flat surface.

# Flask: set values before middleware registration.
app.config.update(
    AIWAF_RATE_WINDOW=10,
    AIWAF_RATE_MAX=20,
    AIWAF_RATE_FLOOD=40,
    AIWAF_RATE_CACHE_BACKEND='redis',
    AIWAF_REDIS_URL='redis://localhost:6379/0',
    AIWAF_RATE_CACHE_KEY_PREFIX='my-service:rate:',
)
AIWAF(app, middlewares=['all'])

Flask's rate middleware defaults to 10 seconds, 20 requests, and flood threshold 40. The website overrides these values in app.py. Node's normalized defaults are 60 seconds, 100 requests, and flood threshold 200. Do not use website thresholds as universal package defaults.

FastAPI nested options

from fastapi import FastAPI
from aiwaf.fast import AIWAF

app = FastAPI()
AIWAF(app, middlewares=['all'],
      rate_limiting={'window_seconds': 10, 'max_requests': 20,
                     'flood_threshold': 40, 'cache_backend': 'redis',
                     'redis_url': 'redis://localhost:6379/0',
                     'cache_key_prefix': 'my-service:rate:'})

The shared environment loader recognizes names such as AIWAF_RATE_WINDOW_SECONDS and AIWAF_RATE_MAX_REQUESTS. Those differ from the Flask/Django flat names. Boolean strings accept true, 1, yes, and on as true; list mappings split comma-separated values. File lists use JSON arrays. Review the environment map before assuming a setting is supported.

Middleware, route policy, and exemptions

all selects the canonical middleware set. auto omits checks based on detected application signals. Explicitly disabled middleware and route exemptions can bypass checks even when their configuration says enabled. Regenerate route manifests after route changes and inspect the selected middleware at runtime.

Default exemptions differ. Django includes administrative/login paths; Flask includes health, crawler, static and asset paths. Private-address behavior also differs from an explicit trusted-client whitelist. Review Python default exemption lists and the policy lifecycle before interpreting a successful local request as a public-client test.

Configure forwarding-header handling with the actual deployment topology. Java exposes trustedProxyCidrs and maxForwardedForEntries. Python and Node extraction use adapter-specific rules; these Java options are not portable knobs. Have the outer proxy overwrite untrusted client forwarding headers, and compare observed client addresses with the intended public client.

Multiple workers and storage

Persistent blacklist files, model storage, logs, and rate counters have separate ownership. A CSV blacklist does not share every in-memory counter. Flask/FastAPI use separate rate-cache settings; install the Redis client required by the selected backend. Flask can fall back to a process-local cache if Redis initialization fails. Verify repeated requests across workers and inspect backend diagnostics.

Node accepts a shared cache implementation; its fallback is process-local. Java Redis shares enforcement state within storageKeyPrefix, supports standalone mode, and defaults to fail_closed. Use the same namespace only for intentionally shared policy/state, and review schema compatibility before mixed-version deployments.

Source default tables

The Python table includes every leaf returned by the shared manager. The Node table includes normalized options, not every raw option consumed by individual modules (for example cache/WASM settings). The Java table includes public AiwafConfig field initializers. Disabled middleware can leave a setting inactive. These tables are a source snapshot, not your effective live configuration.
