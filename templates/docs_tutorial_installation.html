First protected app / Step 1 of 6

Prepare your environment

{% include '_docs_source.html' %}

This tutorial builds a small Flask API and follows one request from the client through AIWAF to the handler and request log. You will see three successful requests followed by a rate-limit response, and then exempt one route without removing protection from the others.

Before you begin

Use Python 3.11 or newer, a terminal, and an empty directory. The commands use the current Python AIWAF API. They do not require Redis, Rust, a trained model, or the AIWAF source checkout. Flask is the teaching example; use the framework guides if you are integrating an existing app.

1. Create a workspace

mkdir aiwaf-demo
cd aiwaf-demo
python -m venv .venv

A virtual environment keeps the tutorial's packages separate from other applications. Run every later command from this directory with that environment active.

2. Activate the environment

Linux and macOS

source .venv/bin/activate

Windows PowerShell

.\.venv\Scripts\Activate.ps1

If your machine names Python python3 or uses the py launcher, use that command to create the environment. Once active, python should refer to its interpreter.

3. Install the framework extra

python -m pip install "aiwaf[flask]"
python -m pip show aiwaf Flask

The flask extra installs the dependencies for the Flask adapter. aiwaf-rust is optional acceleration and is deliberately left out of this first walkthrough. You can add it after you have verified the baseline behavior.

4. Check the import

python -c "from aiwaf.flask import AIWAF; print('Flask adapter ready')"
Flask adapter ready

If the import fails, compare python -m pip --version with the active interpreter. Do not install packages into a different environment to silence the error.

Checkpoint You have an isolated environment and can import the Flask adapter. No server or model is running yet.
