2. Path Generation and Auto Middleware (PathManifestCore.java)

Unlike scripting languages that rely on AST parsing, the Java implementation leverages JVM Reflection to build deterministic route manifests for protection gating, facilitating "auto middleware" orchestration.

  • Introspection & Path Generation: Analyzes java.lang.reflect.Method and Class<?> to extract route signatures, generating a deterministic tree of all endpoints and their supported HTTP methods.
  • API Detection (ApiDetectionCore): Inspects method return types and @RestController / @ResponseBody annotations (in Spring) to accurately classify endpoints as APIs vs HTML Form controllers.
  • Auth Detection (AuthDetectionCore): Uses heuristic matching on method names (e.g., login, authenticate) and paths to flag authentication boundaries.
  • Manifest Compilation: Outputs a compiled PathManifestEntry JSON object that dictates which middleware should run on a given endpoint.
  • Auto Middleware Planning: The AiwafEngine reads these generated properties dynamically at runtime to auto-configure protections:
    • If a route is flagged as an API, it bypasses the HTML Honeypot check automatically.
    • Global configurations (e.g., enabledMiddlewares vs disabledMiddlewares) combined with PathRule overrides allow fine-grained rate limit overwrites or complete bypasses for specific generated paths.

3. Detailed Behavior Notes

  • Path exemptions combine auto-prefixes, configured exemptions, runtime path store, and geo-exempt paths.
  • IP exemptions combine explicit IPs and optional private-IP bypass.
  • Keyword learning runs only when enableKeywordLearning=true and uses malicious-context heuristics (e.g. cmd=, .php, union) with bounded additions (dynamicTopN).
  • Honeypot tracks GET timestamps per ip|path in an internal map; POST checks calculate elapsed time and enforce a minimum duration (minFormTimeSeconds or loginMinFormTimeSeconds) and maximum duration (maxFormPageTimeSeconds).
  • Header validation enforces required headers, suspicious patterns, quality threshold, and size/count caps.
  • Rate keys: GLOBAL_IP=ip, PER_PATH=ip|path; flood gate is evaluated before standard max gate using local memory `requestBuckets` (Deque<Long>).

3. AI Anomaly Model Path

  • Model source: LazyModelProviderCore via aiModelPath. Supports immediate load or background daemon thread preloading (aiBackgroundPreload).
  • Extracts exactly 9 features: path_len, kw_hits, status_code, status_idx, response_time_ms, burst_count (last 10s), total_404 (in recent window), path_depth, and method_is_post.
  • Scoring via IsolationForestCore.score(...) on the payload located at payload["isolation_forest"]["model"].
  • Effective threshold: min(artifact_threshold, config.aiAnomalyScoreThreshold).
  • Behavior confirmation gate: If aiRequireBehaviorConfirmation is true, the anomaly block is suspended until at least aiMinRecentSamplesToBlock requests from that IP are observed within aiRecentWindowSeconds.

4. Model Artifact Lifecycle

  • ModelArtifactIoCore: save/load TrainedModelCore with compatibility checks.
  • ModelArtifactMigrationCore: migrates legacy key names and schema marker iforest-v0 to iforest-v1.
  • LazyModelProviderCore: deferred load, eager/background preload modes.

5. Configuration Compatibility

  • AiwafConfigCompatCore supports structured sections: storage, header_validation, rate_limiting, honeypot, ip_keyword_block, geo_block, ai_anomaly, uuid_tamper, exemptions, path_rules, legitimate_route_hints.
  • Env overlays include: AIWAF_RATE_WINDOW, AIWAF_RATE_MAX, AIWAF_RATE_FLOOD, AIWAF_HEADER_VALIDATION, AIWAF_AI_MODEL_PATH, AIWAF_STORAGE_BACKEND, AIWAF_STORAGE_FILE_PATH, and related keys.

6. Runtime + Integrations + Tests

  • Runtime backends: MemoryStorage, FileStorage, CsvStorage through RuntimeStorage.
  • Stores: ExemptionStore, PathExemptionStore, BlacklistStore, KeywordStore, GeoBlockStore.
  • Spring: AiwafFilter, AiwafInterceptor, AiwafRouteDecisions, annotation model.
  • Servlet: AiwafServletFilter.
  • Tests: core, runtime, spring, and CLI suites under src/test/java/com/aiwaf/*.
