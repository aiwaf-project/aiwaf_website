Scope

  • Environment prerequisites and installation.
  • Spring and Servlet integration patterns.
  • Configuration model and path-rule override behavior.
  • Runtime storage backend setup (memory, file, csv).
  • CLI/admin command surface and parity utilities.

Integration Targets

Framework Agnostic Core

Direct AiwafEngine.evaluate(...) integration with your own request mapper.

Spring MVC

AiwafFilter, AiwafInterceptor, and route annotations for middleware control.

Servlet API

AiwafServletFilter with ServletRequestMapper and response enforcement.

CLI/Admin Ops

AiwafConsole and CoreCli for runtime state and replay analysis.

Runtime Stores

  • ExemptionStore
  • PathExemptionStore
  • BlacklistStore
  • KeywordStore
  • GeoBlockStore
