AIWAF-Java Full Project Reference

Implementation-focused reference for aiwaf-java modules, request contracts, model lifecycle, telemetry, and adapter behavior.

Artifact
io.github.aiwaf-project:aiwaf-java:0.2.0
Java Target
Java 17
Packaging
jar
Primary Integrations
Servlet + Spring MVC

Scope

  • Module boundaries and core runtime contracts.
  • Deterministic request pipeline and state ownership.
  • Configuration semantics and Python-style config compatibility.
  • Model artifact IO, migration, and lazy loading behavior.
  • Runtime telemetry counters/histogram semantics.
  • Integration adapters, CLI surfaces, and test topology.

Core Runtime Contracts

AiwafRequest

Normalized request contract consumed by engine pipeline.

AiwafDecision

Immutable allow/deny result with status code and reason.

AiwafConfig

Runtime policy model for middleware, AI, storage, and observability.

AiwafEngine

Deterministic orchestration with per-stage deny short-circuit behavior.

Engine State Ownership

  • In-memory transient state: rate-limit buckets, honeypot GET timestamps, recent per-IP behavior windows.
  • Persistent/semi-persistent shared state: delegated to RuntimeStorage stores.
