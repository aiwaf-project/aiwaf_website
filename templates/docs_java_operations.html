Ops And Release

Java Operations and Runtime Controls

1. Admin CLI (com.aiwaf.cli.AiwafConsole)

mvn -q -DskipTests exec:java -Dexec.mainClass=com.aiwaf.cli.AiwafConsole -Dexec.args="stats"
java -cp target/classes com.aiwaf.cli.AiwafConsole list all
  • list/add/remove: whitelist, blacklist, keywords, geo, path exemptions.
  • export/import/reset flows.
  • stats and whois operations.

2. Core CLI (CoreCli)

  • analyze-request --request <json_file>
  • analyze-behavior --events <json_file>
  • replay --cases <json_file>
  • list/reset --targets ...

3. Runtime Observability

  • Enable with observabilityEnabled=true.
  • Metrics include request totals, allow/deny totals, blocked-by-status, blocked-by-outcome, middleware trigger counters, and latency histogram (requests.evaluate.latency_ms).
  • Access collector via AiwafEngine.telemetry().
  • Reset via AiwafEngine.clearState().

4. AI Runtime Controls

  • Enablement: aiEnabled, aiModelPath, lazy/background model load flags.
  • Threshold: aiAnomalyScoreThreshold combined with artifact threshold.
  • Behavior confirmation gates: aiRequireBehaviorConfirmation, aiRecentWindowSeconds, aiMinRecentSamplesToBlock.
  • Context capture knobs: storeExtendedBlockInfo, redact/truncate limits.

5. Storage and Persistence Ops

  • Backend: storageBackend = memory, file, or csv.
  • Path: storageFilePath.
  • For restart-stable deployments, avoid memory.

6. Validation Workflows

mvn test
docker compose -f examples/sandbox/docker-compose.yml up -d --build
  • Core/runtime/spring/cli test suites under src/test/java/com/aiwaf/*.
  • Sandbox targets: localhost:8080, localhost:8081, baseline localhost:3001.
  • Attack comparison tools: AttackSuite, CompareResults, CompareResultsModes.

7. Production Guidance

  1. Version path rules and route annotations as policy code.
  2. Tune AI thresholds and confirmation mode per environment.
  3. Validate model compatibility after schema/version bumps.
  4. Keep telemetry enabled during initial rollout phases.
