Ops And Release

CLI, Config, Testing, Packaging

Admin CLI (AiwafConsole)

mvn -q -DskipTests exec:java \
  -Dexec.mainClass=com.aiwaf.cli.AiwafConsole \
  -Dexec.args="stats"

java -cp target/classes com.aiwaf.cli.AiwafConsole list all

Primary Commands

  • stats
  • list [all|whitelist|blacklist|keywords|geo|exempt-path]
  • add/remove <whitelist|blacklist|keyword|geo|exempt-path> ...
  • geo <list|add|remove>, exempt-path <list|add|remove>
  • export, import, reset, whois

Core Parity CLI (CoreCli)

  • analyze-request --request <json_file>
  • analyze-behavior --events <json_file>
  • replay --cases <json_file>
  • list [--targets ...], reset [--targets ...]

Configuration Domains (AiwafConfig)

  • Middleware toggles: header, rate, honeypot, UUID, keyword, geo, method checks
  • Rate controls: scope, window, max, flood, auto-block flags
  • Exemptions: IP/path sets, wildcard/prefix handling, private IP policy
  • Header policy: required headers, quality score, byte/count/length caps
  • Geo policy: allow/block country sets and geo-exempt paths
  • Route overrides: pathRules and middleware-name normalization

Testing And Validation

mvn clean test
mvn clean package
  • Core tests: engine, policy modules, replay, ingest/log IO
  • Runtime tests: memory/file/csv backend parity
  • Spring tests: route decisions and annotation behavior
  • CLI tests: console and manager command handling

Operational Notes

  • Initialize persistent storage explicitly for multi-instance or restart-safe deployments.
  • Use route-level controls to suppress false positives on special endpoints.
  • Tune deny thresholds based on traffic and monitor status-code distribution (403/405/409/429).
  • Validate GeoIP and whois dependencies separately when those features are enabled.
