Purpose And Scope

  • System purpose and architecture.
  • Execution flows for Django, Flask, and FastAPI adapters.
  • Core modules and shared abstractions.
  • Storage, learning, and model lifecycle.
  • Security controls, exemptions, and path rules.
  • CLI and management command surface.
  • Test topology and operational artifacts.
  • Build/release pipeline and packaging internals.

Top-Level Structure

aiwaf/

Library source and shared core.

tests/

Framework-specific and shared test suites.

examples/

Config examples and sandbox replay/comparison harness.

scripts/

Focused benchmark and stress tooling.

Core Dependencies

  • numpy, pandas, scikit-learn, joblib for AI/training.
  • geoip2 for geolocation logic.
  • requests and python-whois for integration tooling.
  • Optional Rust acceleration package: aiwaf-rust.
