Ops, Tests, Release

Operational Surface

Logging And Observability

  • Flask/FastAPI middleware emits access, error, and AIWAF event logs.
  • Django uses RequestLog model and optional CSV middleware logs.
  • core/logs.py provides locking-aware CSV log writing.
  • Helpers include analyze_access_logs, log_analyzer.py, analyze_storage.py, and diagnostics scripts.

CLI And Operator Surfaces

Package CLI

  • aiwaf/cli.py routes to framework handlers.
  • Bare aiwaf defaults to Fast command set.
  • aiwaf-detect bridges into Django training path.

Django Commands

  • Training/list/reset/diagnose paths under aiwaf/django/management/commands/.
  • Geo controls, exemption utilities, model setup/regeneration, blacklist/cache maintenance, WHOIS.

Flask/Fast Commands

  • Flask CLI manages storage/security states and import/export operations.
  • FastAPI CLI delegates to Flask CLI for operational parity.

Design Strengths And Tradeoffs

Strengths

  • Shared core minimizes cross-framework drift.
  • Fallback strategies reduce hard failures under missing deps/storage issues.
  • Route-aware keyword learning lowers false positives.
  • Path-rule + decorator controls allow selective hardening.
  • Rust acceleration is optional, not a hard dependency.

Tradeoffs

  • Behavior differences remain across adapters in specific edge semantics.
  • Adapter maturity is uneven (Django generally deeper).
  • Legacy compatibility layers increase complexity.
  • In-process middleware caches are not distributed by default.
  • Simple fallback stores need stronger concurrency hardening for heavy multi-worker traffic.
