AIWAF End-To-End Setup Guide

1. What This Guide Is

End-to-end setup manual for running AIWAF in real projects across Django, Flask, and FastAPI.

  • Environment prerequisites
  • Installation paths and configuration baselines
  • Storage/model backend options
  • Training, Rust enablement, validation, troubleshooting

2. Prerequisites

Runtime

  • Python 3.8+, pip
  • Running app in Django, Flask, or FastAPI

Recommended For Production

  • Access logs from Nginx/Apache/Gunicorn/Uvicorn
  • Persistent filesystem path for AIWAF data/logs
  • Scheduled training (daily minimum for internet-facing apps)

3. Installation Options

pip install aiwaf
pip install "aiwaf[django]"
pip install "aiwaf[flask]"
pip install "aiwaf[fastapi]"
pip install "aiwaf[rust]"  # optional

Rust mode is optional. AIWAF falls back to Python logic automatically.

4. Shared Configuration Concepts

AIWAF uses flat AIWAF_* keys.

  • AIWAF_ACCESS_LOG
  • AIWAF_DISABLE_AI
  • AIWAF_MIN_AI_LOGS
  • AIWAF_MIN_TRAIN_LOGS
  • AIWAF_FORCE_AI_TRAINING
  • AIWAF_USE_RUST
  • AIWAF_RATE_WINDOW, AIWAF_RATE_MAX, AIWAF_RATE_FLOOD
  • AIWAF_REQUIRED_HEADERS, AIWAF_HEADER_QUALITY_MIN_SCORE
  • AIWAF_EXEMPT_PATHS, AIWAF_EXEMPT_KEYWORDS, AIWAF_ALLOWED_PATH_KEYWORDS
  • AIWAF_GEO_BLOCK_ENABLED, AIWAF_GEO_BLOCK_COUNTRIES, AIWAF_GEO_ALLOW_COUNTRIES

Django Model Artifact Storage

  • AIWAF_MODEL_STORAGE = "file" | "db" | "cache"
  • AIWAF_MODEL_PATH
  • AIWAF_MODEL_STORAGE_FALLBACK

5. Auto Middleware & Path Manifest Setup

AIWAF can automatically tune your middleware protections based on your application's routing structure. By generating a Path Manifest, AIWAF categorizes your endpoints (e.g., API vs HTML Form) and automatically disables unnecessary middlewares (like Honeypots for APIs) and enforces strict rate limits where appropriate.

At startup, AIWAF reads the manifest from .aiwaf/paths.json (or via the path_rules configuration) to auto-configure the execution chain.

If you prefer fine-grained manual control over your middleware stack rather than relying on auto-generation, proceed to the framework-specific "All Middlewares" manual setup sections below.

8. FastAPI Setup (All Middlewares)

Install + Basic Wiring

pip install "aiwaf[fastapi]"

from fastapi import FastAPI
from aiwaf.fast import AIWAF

app = FastAPI()
aiwaf = AIWAF(
    app,
    storage={"backend": "file", "file_path": "aiwaf_data.json"},
    rate_limiting={"enabled": True, "max_requests": 20, "window_seconds": 10, "flood_threshold": 40},
    header_validation={"enabled": True, "quality_threshold": 3},
    geo_block={"enabled": False},
)

Path Rules + Decorators + CLI

aiwaf = AIWAF(
    app,
    path_rules=[
        {"PREFIX": "/health", "DISABLE": ["rate_limit", "ai_anomaly", "header_validation"]},
        {"PREFIX": "/api/heavy", "RATE_LIMIT": {"WINDOW": 10, "MAX": 60, "FLOOD": 120}},
    ],
)

from aiwaf.fast import aiwaf_exempt

@app.get("/health")
@aiwaf_exempt
async def health():
    return {"ok": True}

# CLI
aiwaf fast --help

9-11. Storage, Training, Rust

Runtime Storage Backends

  • memory: local non-persistent tests
  • file: simple persistent single-node runtime
  • csv: human-readable, lock-aware utilities
  • db: SQLite-backed persistent key-value runtime

Multi-Instance Note

For horizontal scaling, use shared/centralized state or a custom storage integration so block/exemption decisions stay consistent.

Rust Enablement

pip install "aiwaf[rust]"
# then set
AIWAF_USE_RUST = True

12-13. Production Checklist And Validation

  • [ ] Framework extra installed.
  • [ ] Access logs configured and readable/writable.
  • [ ] Middleware order reviewed.
  • [ ] Exempt paths configured for health/static/webhooks.
  • [ ] Rate and header policies tuned.
  • [ ] Training scheduled.
  • [ ] Geo-blocking intentionally configured (or disabled).
  • [ ] Observability and log rotation in place.
  • [ ] Verified block and exemption behavior in staging.

Validation Playbook

  1. Smoke: normal/static/health requests should pass.
  2. Rate burst: observe pass then 429, optionally 403 flood block.
  3. Header check: low-header curl should trigger header policy behavior.
  4. Keyword/anomaly check: malicious-style probe should be logged/blocked in staging.

14-17. Troubleshooting, Contributor Setup, Minimal Snippets

Troubleshooting Highlights

  • Django model app errors: ensure "aiwaf.django" in INSTALLED_APPS, rerun migrations.
  • No training: verify access-log path, parseable format, and thresholds.
  • False positives: tune exemptions/header score/path rules/allowed keywords.
  • Missing persistence: validate backend mode and writable dirs.
  • Rust inactive: check pip show aiwaf-rust and AIWAF_USE_RUST=True.

Quick Minimal Config Snippets

# Django
INSTALLED_APPS += ["aiwaf.django"]
MIDDLEWARE += [
    "aiwaf.django.middleware.HeaderValidationMiddleware",
    "aiwaf.django.middleware.IPAndKeywordBlockMiddleware",
]
AIWAF_ACCESS_LOG = "/var/log/nginx/access.log"

# Flask
app.config["AIWAF_USE_CSV"] = True
import aiwaf.flask as aiwaf
aiwaf.register_aiwaf_middlewares(app, middlewares=["ip_keyword_block", "rate_limit"])

# FastAPI
from aiwaf.fast import AIWAF
aiwaf = AIWAF(app)
