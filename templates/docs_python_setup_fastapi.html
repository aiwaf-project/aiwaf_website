How AIWAF works: system architecture

Add AIWAF to a FastAPI application and verify that protection is registered with the live route table.

Before you begin

Use an environment compatible with your framework. This guide assumes a Python application file named app.py. New to middleware? Start with the six-step first protected app tutorial, which includes complete files and expected responses.

1. Install the framework extra

pip install "aiwaf[fastapi]"
pip install "aiwaf[rust]"  # optional native acceleration

Install into the environment used to run your application. Choose an interpreter compatible with the framework and dependencies.

2. Register protection

app.py

from fastapi import FastAPI
from aiwaf.fast import AIWAF

app = FastAPI()

AIWAF(
    app,
    middlewares=["auto"],
    storage={"backend": "memory"},
    header_validation={"enabled": True, "quality_threshold": 3},
    rate_limiting={"enabled": True, "window_seconds": 10, "max_requests": 20},
    logging_middleware={
        "enabled": True,
        "log_dir": "aiwaf_logs",
        "log_format": "json",
    },
)

@app.get("/")
async def home():
    return {"protected": True}

3. Discover your live routes

Run from the application checkout after all routes are registered:

aiwaf init --framework fastapi --app app:app

The default output is .aiwaf/paths.json. Flask and FastAPI require module:object in --app; Flask factories such as app:create_app are supported. Repeat discovery when registered routes change.

4. Scope route exemptions

from aiwaf.fast import aiwaf_exempt, aiwaf_only

@app.get("/health")
@aiwaf_exempt
async def health():
    return {"ok": True}

@app.post("/webhook")
@aiwaf_only("header_validation")
async def webhook():
    return {"accepted": True}

5. Configure the adapter

FastAPI accepts nested constructor dictionaries: rate_limiting, storage, header_validation, and logging_middleware. The earlier example uses those names. Flask/Django flat names such as AIWAF_RATE_MAX are not equivalent constructor arguments. See configuration inputs and precedence for defaults, file/environment loading, and explicit overrides.

Persisted Python models use JSON state; install optional Rust acceleration after the baseline integration is working. A selected anomaly middleware does not establish that a usable trained model has been loaded.

6. Start and verify

python -m pip install uvicorn
python -m uvicorn app:app --port 8000

Open http://127.0.0.1:8000/ in a browser. The example returns {"protected": true}. Confirm enabled middleware, exemptions, and client IP before testing a threshold. A local/private client may be exempt and is not evidence of public-client enforcement.

aiwaf fast --help

Use Python operations for training, model inspection, and state migration. Training requires representative logs in a supported format; setup alone does not train a model.

Production configuration

  • Configure the application to trust forwarding headers only from known proxy CIDRs.
  • Configure the outermost proxy to overwrite client-supplied forwarding headers.
  • Use Redis, a database, or another shared backend when multiple workers must share rate-limit, blacklist, or exemption state.
  • Keep health checks, static assets, and trusted webhook routes explicitly scoped instead of disabling protection globally.
  • Start anomaly detection in observe-only or conservative mode and tune it with representative normal traffic.
  • Rotate logs and exclude secrets, authorization headers, cookies, and personal data.
  • Sign model/configuration artifacts where the runtime supports HMAC verification.
  • Run AIWAF alongside normal secure-development controls and an edge/reverse-proxy layer.
