# Static site conversion

The documentation website now uses Jekyll and GitHub Pages. The Flask application, database integration, AIWAF website middleware, signup form, beta administration, and WSGI deployment files have been removed.

The existing design and documentation remain, with Liquid includes, front matter permalinks, static legacy redirects, browser search, and project-site URL support. SDK integration examples remain in examples/.

See README.md and DEPLOYMENT.md for build, preview, verification, and publishing instructions.
